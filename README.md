# 板橋雙子星空維區｜圖片內嵌版

這一版專門解決 GitHub Pages 圖片不顯示問題。

## 只需要上傳 3 個檔案
- index.html
- style.css
- script.js

所有 Q 版 SVG 圖片已直接嵌入 index.html，
**不需要 assets 資料夾，也不需要另外上傳圖片。**

## GitHub Pages
請把上述三個檔案放在 Repository 根目錄：
- /index.html
- /style.css
- /script.js

然後到 Settings → Pages → Deploy from a branch → main → /(root)

## 如果舊頁面還沒更新
GitHub Pages 有時會有快取，請：
1. 重新整理頁面（Ctrl + F5）
2. 確認新的 index.html 已 Commit
3. 等 GitHub Pages 完成重新部署後再開啟
